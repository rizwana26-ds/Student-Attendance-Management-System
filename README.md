# Student Attendance Management System - Python

A simple and efficient console-based application to manage student attendance records.

## Features
- Add new students with ID and Name
- Mark daily attendance (Present/Absent)
- View records with Present/Absent count and Attendance %
- User-friendly menu driven interface

## Tech Stack
- Python 3.x (Core Python, Lists, Loops)

## How to Run
1. Clone this repo
2. Run `python main.py`
3. Follow the on-screen menu
